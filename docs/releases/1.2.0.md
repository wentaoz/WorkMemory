# WorkMemory 1.2.0

WorkMemory 1.2.0 hardens everyday use on Apple Silicon: launch no longer dies on a busy or unreadable database, Ask Memory stays off the main thread, API keys leave plaintext preferences, and privacy filtering is configurable without dropping real secret-page coverage.

## What's new

- **Safer launch on large workspaces.** One shared SQLite connection, a busy timeout, and no all-archived FTS wipe on every start. Opening the live 207MB / 52k-activity library on this machine takes well under a second.
- **Recoverable database errors.** If the file is locked or unreadable, the app stays up and offers retry, the latest backup, or Reveal in Finder instead of crashing.
- **Ask Memory off the main thread.** Retrieval and embedding run in the background. Search uses FTS first, then ranks a bounded candidate set. Sentence embeddings load lazily and fall back to lexical matching.
- **API keys in Keychain.** Existing `deepseek.apiKey` values are migrated out of UserDefaults.
- **Privacy filter you can edit.** Password managers, login/payment pages, and secret keywords stay blocked. Short English tokens match on word boundaries so `author` and `privacy` are not skipped by mistake. Add extra apps, keywords, domains, or path segments in Settings, or pause capture for 15 minutes / 1 hour.

## Compatibility

- macOS 13 or later.
- Universal build for Apple Silicon and Intel Macs.
- Existing WorkMemory databases open in place. No schema bump.

## Installation

Drag `WorkMemory.app` to Applications. This public build is signed with an Apple Development identity but is **not notarized**. If macOS blocks the first launch, right-click the app and choose **Open**.
